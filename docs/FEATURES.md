# Feature coverage

This describes working behavior in version 2.0. Provider configuration is distinct from features not implemented.

| ----------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Booking     | Public booking, multiple services, group transaction, account booking, private manage links, rescheduling, cancellation policy          | Group builder chooses each guest's professional/time; it does not optimize a whole party automatically. Paid visits require studio help for public changes.         |
| Scheduling  | Day/week/month, drag to a date, move dialog, shifts, buffers, time off, resource conflict prevention                                    | Resources are explicitly assigned by staff; public customers do not choose a chair.                                                                                 |
| Recurrence  | Weekly, fortnightly, four-week series; all-or-nothing initial creation; future move/cancel API; rolling extension; pause/resume         | Conflicts pause extension and surface the reason in Operations.                                                                                                     |

## External products not represented as finished features

AI telephone reception/call routing, financing/underwriting, bank onboarding/payouts, native mobile app distribution, payment hardware and marketplace partner integrations are not implemented in this repository. These need separate product/integration work and, for financial/telephony services, provider arrangements. Adding API keys alone does not supply them.

## Financial behavior

Amounts use integer USD cents. Server-side calculations and transactions control inventory, gift balances, points and credits. Cash actions record funds already collected. Card orders become paid only after a verified Stripe webhook with the matching currency/amount. Returning to the success URL never fulfills an order. Online payment and service completion are separate states.

Deposits are separate payment orders and reduce the remaining checkout balance without reducing the taxable service amount. Reports show cash collected in the order-created date window, including deposits; gift issuance is excluded from earned sales and balances are reported as a liability. This is an operational report, not accrual accounting or tax filing. Configure the correct location tax rate for your business; automatic tax determination is not enabled.
